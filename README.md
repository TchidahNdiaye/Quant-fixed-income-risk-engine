# quant-fixed-income-volatility-risk-engine
Ce projet consiste à construire une plateforme quantitative de construction de courbes, de valorisation d'instruments, de modélisation stochastiques des taux et de la volatilité à partir des données de marché. Elle permettra également de réaliser les analyses du risque de spread, de recherche systématique, la construction de portefeuille et l'ALM.
